# Эмулятор оболочки ОС (Вариант №15)

Консольный эмулятор командной строки UNIX-подобной ОС, реализованный на языке C++. Проект выполняется поэтапно в рамках практической работы.

## Описание проекта
Эмулятор должен имитировать базовый интерфейс командной строки (REPL) с поддержкой виртуальной файловой системы (VFS). Программа позволяет вводить команды, обрабатывает их и выводит результат.

## Этап 1: REPL
- Приглашение к вводу в формате `my_vfs>`.
- Простой парсер, разбивающий ввод на команду и аргументы.
- Команды-заглушки `ls` и `cd`, выводящие свои имя и аргументы.
- Команда `exit` для завершения работы.
- Обработка ошибок при вводе неизвестных команд.

## Этап 2: Конфигурация
Программа поддерживает параметры командной строки:
- `--vfs <путь>` — путь к JSON-файлу виртуальной файловой системы.
- `--script <путь>` — путь к стартовому скрипту с командами.

При запуске выводится отладочная информация о переданных параметрах.

### Сборка и запуск
1. Откройте файл `shell_emulator.sln` в Visual Studio 2022.
2. Нажмите `F5` для сборки и запуска.

### Тестирование (скрипты ОС)
В папке `scripts` находятся скрипты для Windows:
- `run_test_with_vfs.bat` — запускает эмулятор с параметрами `--vfs` и `--script`.
- `run_test_no_vfs.bat` — запускает эмулятор только с параметром `--script`.

Для тестирования запустите нужный `.bat` файл.
