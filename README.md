Программа: Эмулятор оболочки ОС (Вариант №15)

Консольный эмулятор командной строки UNIX-подобной ОС, реализованный на языке C++. Проект выполняется поэтапно в рамках практической работы.

## Описание проекта
Эмулятор имитирует базовый интерфейс командной строки (REPL) с поддержкой виртуальной файловой системы (VFS). Программа позволяет вводить команды, обрабатывает их и выводит результат, работая в бесконечном цикле до команды `exit`.
