# Эмулятор оболочки ОС (Вариант №15)

Консольный эмулятор командной строки UNIX-подобной ОС, реализованный на языке C++. Проект выполняется поэтапно в рамках практической работы.

## Описание проекта
Эмулятор должен имитировать базовый интерфейс командной строки (REPL) с поддержкой виртуальной файловой системы (VFS). Программа позволяет вводить команды, обрабатывает их и выводит результат.

## Этап 1: REPL
- Приглашение к вводу в формате `my_vfs>`.
- Простой парсер, разбивающий ввод на команду и аргументы.
- Команды-заглушки `ls` и `cd`, выводящие свои имя и аргументы.
- Команда `exit` для завершения работы.
- Обработка ошибок при вводе неизвестных команд.

## Этап 2: Конфигурация
Программа поддерживает параметры командной строки:
- `--vfs <путь>` — путь к JSON-файлу виртуальной файловой системы.
- `--script <путь>` — путь к стартовому скрипту с командами.

При запуске выводится отладочная информация о переданных параметрах.

## Этап 3: VFS (Виртуальная файловая система)
- Загрузка структуры папок и файлов из JSON-файлов (все операции происходят в памяти).
- Вывод `motd` (Message of the Day) при старте, если он есть в корне.
- Команды `ls` и `cd` работают с виртуальными папками.
- Обработка ошибок загрузки (файл не найден, неверный формат JSON).

## Сборка и запуск
Для работы проекта требуется библиотека **nlohmann/json** (header-only). 
1. Скачайте файл `json.hpp` (версия 3.12.0) с официального репозитория: https://github.com/nlohmann/json/releases/download/v3.12.0/json.hpp
2. Положите скачанный файл в папку `src` (рядом с `main.cpp`).
3. Откройте файл `shell_emulator.sln` в Visual Studio 2022.
4. Нажмите `F5` для сборки и запуска.

## Тестирование (скрипты ОС)
В папке `data` находятся тестовые VFS-файлы:
- `minimal.json` — минимальная VFS (одна папка и один файл).
- `multiple_files.json` — VFS с несколькими файлами в корне.
- `deep_nested.json` — VFS с глубокой вложенностью папок (3+ уровня).

В папке `scripts` находятся скрипты для Windows (`.bat`), которые запускают эмулятор с разными параметрами:
- `run_test_with_vfs.bat` — запускает с параметрами `--vfs` и `--script`.
- `run_test_no_vfs.bat` — запускает только с параметром `--script`.
- `run_test_deep.bat` — тестирование глубокой VFS со скриптом всех команд.
- `run_test_multi.bat` — тестирование VFS с множеством файлов.

Для тестирования запустите нужный `.bat` файл.
